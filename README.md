# eSpeak BR NVDA Add-on

## Descrição em Português

Este complemento é uma versão alternativa do eSpeak NG para o Português Brasileiro.

Você pode baixá-lo aqui: https://github.com/fabiolimace/espeak-br-nvda-addon/releases.

Se você já se sente confortável com o sintetizador eSpeak que vem integrado ao NVDA, é provável que não goste desta versão do eSpeak. Portanto, por favor, NÃO instale este complemento.

## Description in English

This add-on is an alternative version of eSpeak NG for Brazilian Portuguese.

You can download it here: https://github.com/fabiolimace/espeak-br-nvda-addon/releases.

If you are already comfortable with the eSpeak synthesizer that comes built into NVDA, you might not like this version of eSpeak. Therefore, please DO NOT install this add-on.
